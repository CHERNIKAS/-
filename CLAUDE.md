# CostNote (ПЕРЕУЧЁТ)

Учёт трат: Telegram-бот `@costnote_bot`, Mini App `https://costnote.site`, коннектор для Claude (`/mcp`).

## Правила работы — обязательны

1. **Любые изменения — только с разрешения пользователя.** Правка кода, коммит, пуш,
   деплой, миграция, запись в базу, установка пакетов, перезапуск сервисов: сначала
   сказать, что именно собираешься сделать, и ждать явного «да». Разрешение действует
   на одно названное действие, а не на всё подряд.
2. **Не выходить за папку проекта.** Работаем внутри папки этого репозитория. Читать,
   менять или запускать что-либо в других папках (соседние проекты, `/opt`, `/etc`,
   домашние каталоги) — только спросив и получив разрешение. Это касается и `cd`,
   и путей в командах.
3. **Чужие проекты не трогать никогда.** На сервере живут другие проекты. Их файлы,
   контейнеры, базы и настройки не читать и не менять без прямой просьбы пользователя.
4. **Ничего не удалять без разрешения.** Ни файлы, ни данные, ни контейнеры, ни ветки.
5. **Перед изменением данных в проде — бэкап базы**, и только после разрешения.
6. **Секреты не выводить.** Токены, ключи, пароли из `.env` и `.secrets/` не печатать
   в ответах и логах.
7. Если просьба неясна или действие необратимо — спросить, а не угадывать.

## Устройство

pnpm-монорепозиторий, TypeScript:

- `packages/core` — общий слой: разбор текста, импорт выписок, данные (Drizzle + PostgreSQL 16).
- `apps/bot` — бот на grammY, расписание (напоминания, итоги, регулярные платежи).
- `apps/api` — Fastify: API приложения (`/api/*`, вход по подписи Telegram) и коннектор
  Claude (`/mcp`, OAuth с подтверждением кодом в боте).
- `apps/web` — Mini App на React + Vite.
- `migrations/` — миграции Drizzle (`npx drizzle-kit generate --name <имя>`).

Ключевые понятия: книги (личная, общая, бизнес; активная — `users.active_ledger_id`),
виды операций (расход, доход, перевод), пары переводов, возвраты гасят покупку,
баланс — движения, а не число. Все суммы хранятся с курсом к USD на дату операции.

## Проверки

```bash
pnpm -r test
```

Тесты с базой идут на PGlite (Postgres в памяти), сеть в тестах выключена.
Типы: `npx tsc --noEmit -p .` в каждом пакете.

## Деплой (только с разрешения пользователя)

Прод: Docker Compose, приложение в `/opt/costnote/app`, настройки в `/opt/costnote/.env`.
Деплой — `git push`, затем на сервере под root:

```bash
cd /opt/costnote/app && git pull && docker compose --env-file ../.env -f docker-compose.prod.yml up -d --build api bot web
```

Миграции: `docker compose ... exec -T bot pnpm migrate`. Перед миграцией или правкой
данных — бэкап: `pg_dump` в `/opt/costnote/backups/`.
