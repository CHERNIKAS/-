# Деплой

Сервер `95.217.98.125`, каталог `/opt/costnote`.

## Важное про этот сервер

На машине живут ещё около двадцати проектов, а порты 80 и 443 держит
**Traefik от Coolify**. Свой веб-сервер ставить нельзя — он подерётся за порты
и уронит всё разом.

Поэтому costnote прицепляется к существующему Traefik метками, как это уже
сделано у соседнего проекта: внешняя сеть `coolify`, роутер на
`Host(costnote.site)`, сертификат через `certresolver=letsencrypt`.
Порты на хост не публикуются вообще — postgres и redis доступны только
внутри сети стека, чтобы не конфликтовать с чужими на 5432 и 6379.

## Что где

- `/opt/costnote/.env` — пароль базы, создаётся один раз при первом деплое.
- `/opt/costnote/docker-compose.yml` — копия `docker-compose.prod.yml` из репозитория.
- Домен `costnote.site`, A-записи `@` и `www` → `95.217.98.125`.

## Команды

```bash
ssh -i .secrets/server_ed25519 root@95.217.98.125
cd /opt/costnote
docker compose up -d
docker compose ps
docker compose logs -f app
```
